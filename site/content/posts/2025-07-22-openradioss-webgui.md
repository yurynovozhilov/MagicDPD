На днях был опубликован новое открытое решение по визуализации результатов OpenRadioss в WebUI

Исходный код доступен в открытом доступе по лицензии AGPL. Версия для конечных пользователей будет доступна в ближайшее время! 

Во-первых, это красиво... Во-вторых, это заменяет сравнительно быстрый ParaView на модный набор Web виджетов, которые, по моему опыту с pyDPF (собранном примерно на том же стеке технологий) будут тормозить как не в себя. Короче, это решение не для инженеров, которые занимаются расчетами, это решение для построение вертикальных приложений.
