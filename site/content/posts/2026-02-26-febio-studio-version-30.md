У открытого проекта FEBio (открытый нелинейный FEM решатель заточенный под биомеханику) вышел большой релиз их GUI/среды создания проектов. Вообще, мне кажется, что это большая редкость, когда в добавку к открытому и сложному решателю, его разработчики делают еще и графический интерфейс, а не заставляют пользователей формулировать все задачи сразу в текстовом виде.

Новые фишки в GUI:
- FEBio Monitor — интерактивный запуск FEBio прямо из GUI с визуальным просмотром состояния модели в процессе решения.
- FEBio Reports — подробный анализ выполненного расчёта. Отчёты можно генерировать и из лог-файлов.
- Поддержка Python — встроенный редактор и интерпретатор Python 3.13.1 для написания скриптов. Внешний Python-модуль обещают в следующем релизе.
- Генерация FEBio плагинов из интерфейса FBS через визард — создание, редактирование и компиляция плагинов без выхода из студии.
- Plugin Repository — репозиторий плагинов от сообщества с возможностью быстрой установки.
