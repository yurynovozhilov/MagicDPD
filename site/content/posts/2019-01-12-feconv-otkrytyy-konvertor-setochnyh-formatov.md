В некоторых случаях любознательным CAE специалистам может потребоваться конвертировать сетку из одного формата в другой. Это может оказаться весьма нетривиальной задачей. С такой задачей поможет справиться бесплатная консольная утилита&nbsp;FEconv с открытым кодом.
  Что можно подать на вход:
  
    ANSYS (.msh)
    I-Deas Universal (.unv)
    VTK-XML Unstructured Grid (.vtu)
    MD Nastran input file (.bdf)
    COMSOL mesh file (.mphtxt)
    FLUX mesh file (.pf3)
    Modulef-like Formatted Mesh (.mfm)
    Modulef-like Unformatted Mesh (.mum)
    FreFem++ Tetrahedral и/или Triangular Lagrange P1 Mesh (.msh)
    FreFem++ Tetrahedral Lagrange P1 Mesh (.mesh)
    Gmsh MSH ASCII (.msh)
  


  Что можно получить в итоге:
  
    
      ANSYS (.msh)
      I-Deas Universal (.unv)
      VTK-XML Unstructured Grid (.vtu)
      COMSOL mesh file (.mphtxt)
      FLUX mesh file (.pf3)
      Modulef-like Formatted Mesh (.mfm)
      Modulef-like Unformatted Mesh (.mum)
      FreFem++ Tetrahedral и/или Triangular Lagrange P1 Mesh (.msh)
      FreFem++ Tetrahedral Lagrange P1 Mesh (.mesh)
      Gmsh MSH ASCII (.msh)
