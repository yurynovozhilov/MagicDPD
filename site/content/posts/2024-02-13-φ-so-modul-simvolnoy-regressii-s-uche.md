Φ-SO - модуль символьной регрессии с учетом ограничения единиц измерения физических величин

Символьная регрессия - это изучение алгоритмов, автоматизирующих поиск аналитических выражений, которые соответствуют данным.

Φ-SO - система физической символьной оптимизации для восстановления аналитических символьных выражений из данных с учетом ограничений на единицы измерения физических величин. Последнее полезно не только для устранения физически невозможных решений, но и потому, что "грамматические" правила анализа размерностей существенно ограничивают свободу генератора уравнений, что значительно повышает производительность.

Алгоритм можно использовать для подгонки бесшумных данных, что может быть полезно, например, при попытке вывести аналитическое свойство физической модели, а также для получения аналитических приближений к зашумленным данным.
