Code USA

Одним из продуктов LSTC был и является Code USA. И тут USA - это Underwater Shock Analisys. Основная задача кода заключается  для расчета переходных процессов в погруженных конструкциях под воздействием сферической ударной волны с произвольным профилем давления и расположением источника. Ну вы наверно догадываетесь о каких объектах и о каких ударных волнах тут идет речь. Короче, код доступен сугубо ограниченному кругу лиц, и я очень удивлюсь, если когда-нибудь получу к нему доступ.

Однако, в сети можно легко найти официальною первую версию документации по коду. Лодфаги наслаждаются, а я пишу спецкурс по ударным волнам и вызрывам.
