meshio — конвертор сеток на Python


На сей раз нас ждет более современный корвертор сетки. В отличии от FEconv, проект meshio написан на Python 3, а не на архаичном Fortran. Да и собирать его не надо, что также облегчает использование — просто выполните команду «pip3 install -U meshio», и все готово к использованию на любой операционной системе.
meshio поддерживает работу со следующими форматами CAE сеток:

Abaqus
ANSYS msh
DOLFIN XML
Exodus
H5M
Kratos/MDPA
Medit
MED/Salome
Gmsh (versions 2 and 4)
OFF
PERMAS
STL
SVG (2D only, output only)
VTK
VTU
XDMF
