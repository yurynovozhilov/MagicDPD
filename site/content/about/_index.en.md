title: "About the Project"
---

Some think it's magic — but for us, it's just work. We share insights on the development of CAE technologies, computational systems, and other wizardry that enables building great products!

The MagicDPD archive collects posts from the eponymous VK community and presents them in a convenient format.

The raw data is stored in JSON dumps at the repository root. Scripts clean the text, fetch images, and convert everything into Markdown. The static site is now built with [Hugo](https://gohugo.io), so it can be rebuilt locally without network access, and media content is served directly from the `static/assets` directory.

The repository and tools can be adapted for a different source — simply replace the source JSON and re-run the generator.
