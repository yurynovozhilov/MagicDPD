ViCAS3D

10.07.2024 · Автор: GlukRazor · Источник: TG · Оригинал

ViCAS3D

Иногда просто хочется по залипать на ударные волны. Вот например на результаты решателя сжимаемого течения использующего метод погруженной границей ViCAS3D (Viscous Cartesian All-Speed code for 3D flows). Он моделирует взаимодействие двумерного сверхзвукового потока с массивом из пяти цилиндров. Взаимодействие между ударными волнами и отбрасываемыми вихрями визуализируется с помощью численных контуров Шлирена и вихревых потоков.

https://youtu.be/lvbygQltvzo

IGA в Abaqus

Конкуренция - это хорошо. Пока Ansys LST все еще делают свой “сеточный” генератор для IGA на сцену выходит другой тяжеловес. Консалтинговая компания Global Engineering & Materials, Inc. написала свой набор инструментов для IGA моделирования в Abaqus. 01.07.2024 · Автор: GlukRazor · Источник: TG · Оригинал

MeshAnything - с ваших слов сетка построена

Данный код использует часть функционала MeshGPT для генерации упрощенных поверхностных треугольных сеток. На вход данная модель получает данные в куче форматов: облако точек, высоко полигональная модель, аналитическая геометрия, картинка аналитической геометрии или даже совестное описание. Делаем ставки: через сколько месяцев у нас появятся AI сеточные генераторы для FEM/CFD расчетов?

https://buaacyw.github.io/mesh-anything/
