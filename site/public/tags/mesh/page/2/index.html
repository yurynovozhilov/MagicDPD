FEconv - открытый конвертор сеточных форматов

В некоторых случаях любознательным CAE специалистам может потребоваться конвертировать сетку из одного формата в другой. Это может оказаться весьма нетривиальной задачей. С такой задачей поможет справиться бесплатная консольная утилита FEconv с открытым кодом. Что можно подать на вход:

ANSYS (.msh) I-Deas Universal (.unv) VTK-XML Unstructured Grid (.vtu) MD Nastran input file (.bdf) COMSOL mesh file (.mphtxt) FLUX mesh file (.pf3) Modulef-like Formatted Mesh (.mfm) Modulef-like Unformatted Mesh (.mum) FreFem++ Tetrahedral и/или Triangular Lagrange P1 Mesh (.msh) FreFem++ Tetrahedral Lagrange P1 Mesh (.mesh) Gmsh MSH ASCII (.msh)

HexaLab.net - бесплатный сервис оценки качества hex сеток

Коллеги из MeshLab представили сервис, позволяющий визуализировать и оценивать hex сетки в форматах .mesh и .vtk прямо в вашем браузере. Мне больше всего в этом сервисе понравилось то, что если у вас нет подходящей сетки, то вы можете выбрать готовые модели из встроенного списка литературы (!!!) - у вас сразу есть куча примеров хороших сеток.

Сервис довольно приятен по интерфейсу и работает в любом современном браузеле с поддержкой WebGL.

LayTracks3D — новый алгоритм генерации ALL-HEX сетки

Периодически я просматриваю интернет на тему новых сеточных генераторов для своих задач. Так как в основном я работаю в LS-DYNA, то полностью hex сетка высокого качества мне очень нужна. Конечно, никто не отменял работу с геометрией для подготовки тотального sweep, но эта рутинная работа отнимает очень много времени.

На прошедших выходных я набрел на цикл публикаций Сандийских Национальных лабораторий по их алгоритму LayTracks3D. Судя по материалам публикации, данный алгоритм может решить проблему автоматизированного all-hex, если дойдет до коммерческой реализации.
