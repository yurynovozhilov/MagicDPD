Лекция по бессеточному методу Галеркина для сверхбольших деф

Один из самых перспективных методов моделирования задач изменения формы — бессеточный метод Галеркина (Element Free Galerkin, EFG). Он реализован в моей любимой LS-DYNA для SHELL и SOLID постановок в Explicit и Implicit расчетных схемах. Поддерживает связанный термопрочностной расчет, не обладает эффектом песочных часов, инициализируется на основе обычной hex или tet сетки. В общем пока сплошные плюсы. Однако, пока он выглядит «магическим», так как трудно понять, как именно он работает.

Посему я предлагаю вам очень интересную лекцию профессора университета Калифорнии (Сан Диего) Дж. С. Чена (J.S. Chen), которую он прочел в Стэнфорде в 2017 году (https://blume.stanford.edu/event/seminar/recent-advances-accelerated-and-stabilized-meshfree-method-modeling-manmade-and). Поразительно простой и наглядный рассказ такой сложной темы.

Расчеты в LS-DYNA на кластерах Windows HPC Cluster

DYNAmore выпустили инструкцию по настройке и работе распределённого решетеля LS-DYNA на кластерах под управлением MS Windows HPC Pack 2016. Инструкция полезная, но на самом деле вам достаточно знать следующий набор команд:

SET LSTC_MEMORY=auto job submit /jobname: /numcores: /workdir: mpiexec -np i= jobid=

Ну а если вы используете лицензии ANSYS LS-DYNA, то в начало надо добавить еще такое:

set LSTC_LICENSE=ANSYS set ANSYSLMD_LICENSE_FILE=1055@ set ANSYSLI_SERVERS=2325@

Исходный документ тут: https://project.dynamore.se/public/windowscluster12
