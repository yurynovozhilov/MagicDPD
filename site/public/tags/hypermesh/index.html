История современного КЭ

В школе я очень не любил историю — мне было не очень интересно, и я совершенно не мог запомнить даты. Но в последнее время история стала мне очень интересна. Только это не история завоеваний, а история становления современного CAE софта. Я с большим удовольствием ищу и изучаю материалы про то, как это было, когда компьютеры были большими. Коллеги из Multimechanics сделали небольшой, но интересный обзор начала вычислительной механики. #Altair в рамках учебной инициативы Altair University предлагает вгсе желающим скачать учебник/методическое пособие “Practical Aspects of Finite Element Simulation (a Study Guide)”. Я уже уже получил свой экземпляр - книга большая и хорошо написанная, содержит много интересного материала по #FEM как для явных, так и для неявных решателей. Конечно все написано вокруг ПО Altair, но теоретическая часть пригодится всем.

Краткое содержание 503 страниц издания:

  1. CAE-Driven Design Process
  2. Analysis Types
  3. Introduction To Finite Element Analysis
  4. What Is Needed To Run A Finite Element Analysis?
  5. Strategic Planning
  6. Common Mistakes And Errors
  7. Consistent Units
  8. Geometry In HyperMesh
  9. Introduction To Meshing
  10. 1D Meshing With HyperMesh
  11. 2D Meshing With HyperMesh
  12. 3D Meshing with HyperMesh
  13. Element Quality And Checks
  14. Linear Elastic Material Information
  15. Boundary Conditions And Loads
  16. Linear Static Analysis
  17. Modal Analysis
  18. Linear Buckling Analysis
  19. Nonlinear Analysis
  20. Post-Processing
  21. Getting Started With HyperWorks
  22. Preparing For An Interview
