Друзья, у моего бывшего коллеги и хорошего человека есть вакансия на PhD студента или Postdoc в New Mexico Tech (США).

Учёба бесплатная со стипендией (в конце текста более точные пояснения). Это хороший путь для эмиграции.

Надо будет работать над исследовательскими проектами по умным волокнам с автономным питанием для не инвазивных носимых устройств мониторинга здоровья, по гибридному производству композитов из нескольких материалов, по молекулярному моделированию процессов/структур/свойств в гибридном производстве. Проекты спонсируются #NASA, #NIH (Национальный Институт Здоровья) и Socorro Ventures (венчурный фонд). Возможно, надо будет вести лабораторные занятия.

Минимальные требования:

  1. Английский уровня между Intermediate и Upper Intermediate
  2. Степень бакалавра в области машиностроения, механики, материаловедения или связанных с ними областей
  3. Опыт исследований

Ушел из жизни Ричард МакНил, один из отцов MSC и Nastran

Ушел из жизни Ричард МакНил, один из отцов MSC и Nastran

Доктор Ричард МакНил (Dr. Richard H. MacNeal), один из отцов MSC Software и MSC Nastran, скончался 29 января 2018 года в возрасте 94 лет. На протяжении 54 лет своей жизни он занимался развитием индустрии CAE.

[caption id=“attachment_6167” align=“aligncenter” width=“847”] Роберт Швендлер (слева) и Ричард МакНил (справа) работают над космической программой в 1960-х[/caption]

В 1963 году Ричард МакНил и Роберт Швендлер (Robert Schwendler) основали компанию MacNeal-Schwendler Corporation (MSC). Под руководством МакНила в MSC разработали их первый инструмент для решения задач механики SADSAM (Structural Analysis by Digital Simulation of Analog Methods). В 1965 году МакНил начал участвовать в программе по созданию решателя задач механики для NASA. Код предназначенный для решения задач, возникавших в ходе планирования первого полета человека на Луну, получил название Nastran (NASA STRucture ANalysis). В 1971 году компания MSC Software выпустила коммерческую версию Nastran, получившую название MSC.Nastran.

NASA считает аэродинамику квадрокоптеров

NASA считает аэродинамику квадрокоптеров Специалисты NASA рассказали о своем проекте по расчету дронов в собственном CFD коде OVERFLOW.

Первым пробным расчетом стал квадрокоптер, однако на будущее есть планы на моделирование дронов с большим количеством несущих винтов. Расчет выполнен при помощи решателя  OVERFLOW CFD на химерных сетках, созданных при помощи Chimera Grid Tool. Естественно, не обошлось без HPC: мощности для расчетов были предоставлены  NASA Advanced Supercomputing (NAS) Division.

Немного про код OVERFLOW. OVERFLOW 2 предназначен для расчета течений жидкостей и газов с учетом сжимаемости и вязкости. Код специально заточен для расчетов тел со сложной геометрией. Расчет ведется на структурированных химерных сетках. Есть возможность расчета подвижных тел и движения тел под действием аэродинамических сил. Код бесплатно доступен по запросу для использования в США.

Ничего особенного, просто #CFD код #CFL3D от #NASA, разрабатываемый более 35 лет доступен жалеющим на #GitHub.

Цитата из описания кода с его сайта: “CFL3D is a structured-grid, cell-centered, upwind-biased, Reynolds-averaged Navier-Stokes (RANS) code. It can be run in parallel on multiple grid zones with point-matched, patched, overset, or embedded connectivities. Both multigrid and mesh sequencing are available in time-accurate or steady-state modes.”
