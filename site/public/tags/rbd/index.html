Универсальный механизм

Универсальный Механизма (UM) — отечественный софт из Брянска для моделирования кинематики и динамики систем. Включает кучу инструментов для моделирования гусеничных машин, железнодорожных экипажей, прогнозирования усталостной долговечности в связке с ANSYS или Nastran, прогнозирования износа колес и рельс. Встречаем ANSYS Motion

Встречаем ANSYS Motion

Без присущего крупным компаниям шума, ANSYS в релизе 2019 R1 выкатил новый продукт под названием ANSYS Motion. Это принципиально новый решатель в привычном нам интерфейсе ANSYS Mechanical.

Данный решатель предназначен, судя по описанию, конкурировать с лучшими представителями отрасли, такими как Adams.

При этом он поддерживает работу не только с твердыми, но и с «гибкими» темами — например с зубчатыми приводными ремнями.

Более подробной информации о продукте пока нет — будем вместе изучать его возможности.

#Algoryx - разработчик Dynamics for #SpaceClaim выкатил новые фишки своего ПО

Из решатель #AGX Dynamics, который является сердцем Dynamics for #SpaceClaim - системы для расчета твердотельной динамики (#RBD) - теперь умеет решать задачи в #DEM постановке. При этом, используется не сферические частицы (привет #LSDYNA) и их кластеры (привет #EDEM), а частицы произвольной формы (привет #Rocky). Такую постановку метода дискретных элементов разработчики окрестили #NDEM (non-smooth discrete element methods). И это все помимо возможности моделировать поведение кабелей и тросов.
