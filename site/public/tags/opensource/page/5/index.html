Привет всем, кто пишет свой движок топологической оптимизации от #opensource проекта #ToPy.

Lat-Net: Compressing Lattice Boltzmann Flow Simulations using Deep Neural Networks - такое интересное название носит #opensource проект, про который я пишу сегодня.

Суть проекта заключается в подмене #CFD расчета методом #Lattice #Boltzmann на нейронную сеть. Причем, если верить авторам, то натренировав нейрону на грубой “сетке” можно надеются на достаточно точный расчет на мелкой “сетке”.

Это конечно не супер точный #CFD подход, но зато можно быстро получить оценочное решение вашей задачи экономя ресурсы.

Вышел OpenFOAM 5.0

OpenFOAM 5.0 | OpenFOAM OpenFOAM-5.0 is a snapshot of the OpenFOAM development version released on July 26th 2017. It provides new functionality and major improvements to existing code, with strict demands on usability, reliability and maintainability. openfoam.org

Вышел OpenFOAM 5.0 https://openfoam.org/version/5-0/

Вышел 5-ый мажорный релиз #OpenFOAM - #opensource #CFD и не только. В новом релизе появилось множество новых функций. Особенно авторы отмечают три фишки:

  • Моделирование волн на свободной поверхности (https://cfd.direct/openfoam/free-software/waves/)
  • Работа с параллельным вводом/выводом (https://openfoam.org/news/parallel-io/)
  • Барицентрическое отслеживание движения (Barycentric Tracking) - принципиально новый механизм отслеживания движения частей модели (https://cfd.direct/openfoam/free-software/barycentric-tracking/)
