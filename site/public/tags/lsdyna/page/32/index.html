Сравнительно новая, но многообещающая методика расчета воздействия взрыв на объекты на основе метода взрыва частиц (particle blast method, PBM).

Данный подход является расширением метода корпускулярный частиц (corpuscular particle method, CPM) изначально был реализованного в LS-DYNA для моделирования подушек безопастности. Метод работает в лагранжевой домене, что существенно упрощает постановку задачи.

В связке с DEM метод PBM может быть использован для моделирования осколочного воздействия.

В статье PBM показывает себя более эффективным, с вычислительной точки зрения. Кроме того, есть существенные преимущества по точности в сравнении с классическим моделированию взрыва в эйлеровом домене.

Вчера состоялся новый релиз LS-DYNA под версией 8.0.0 R8.95309.

Из принципиально нового:

  • *SET_POROUS_ALE для пористости тел в ALE постановке
  • *ALE_SWITCH_MMG для переопределения многообразных жидкостей в процессе расчета
  • *BOUNDARY_SPC_SYMMETRY_PLANE (ну наконец-то) гранитное условие плоскости симметрии работающее даже при динамическом перестроении сетки
  • *DEFINE_PBLAST_GEOMETRY для задания сложной геометрии *PARTICLE_BLAST
  • *CONTROL_MAT для возможности в одном месте подключить для всех тел *MAT_ADD_ERROSION
  • *INITIAL_LAG_MAPPING позволяющия при растрате переходит от плоской к трехмерной постановке для лагренжевых сеток
  • *DEFINE_ELEMENT_DEATH для контролируемой смерти элементов
  • *DEFINE_ADAPTIVE_SOLID_TO_DES для адаптивного переключения умерших элементов в DEM частицы!
  • *INCLUDE_AUTO_OFFSET для автоматической перенумерация сборных моделей в случае конфликтов номеров элементов
  • появились 20 узловой Solid элементы!
  • несколько новых моделей материалов для EM и CFD.
