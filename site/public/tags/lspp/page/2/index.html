Упрощенный запуск LS-DYNA

How to LS-Run - Easily start LS-DYNA Simulations LS-Run is a new graphical control center to start LS-DYNA simulations with either SMP or MPP versions of LS-DYNA. It is included in the latest LS-PrePost rel... www.youtube.com

Упрощенный запуск LS-DYNA https://www.youtube.com/watch?v=dVypwLW6gQw

Детище #LSTC трудно не только освоить, но и просто запустить. Однако, начиная с версии 4.3 в составе LS-PrePost идет небольшая утилитка LS-Run, которая обеспечивает не только запуск #LSDYNA, но и самого LS-PrePost над нужным d3plot.

Основные фишки ПО:

  • Параметрическая командная строка LS-DYNA
  • Поддержка SMP/MPP
  • Работа на Linux и Windows
  • Исполнение командной строки локально или удаленно
  • Администрирование запущенных задач
  • Постановка задач в очередь (!!!)

Автоматизация в LS-PrePost

Error | VK vk.com

Автоматизация в LS-PrePost http://www.lstc.com/lspp/content/other/command/command.shtml

Полное отсутствие #GUI у чудовищно мощного решателя LS-DYNA может быть здорово компенсировано возможностями бесплатного пер/пост процессора LS-PrePost от #LSTC. Данный инструмент конечно немного устарел по интерфейсу, зато только он может справиться с сотнями гигабайт данных результатов практически на лету. Кроме того, у него есть возможность создания скриптов автоматизации на основе своего собственного #CLI. Документацию по CLI найти сложно, так что я сейчас сложу все ссылки на нее в данном посте. Кроме того, не забывайте смотреть на интерактивную запись сессии.
