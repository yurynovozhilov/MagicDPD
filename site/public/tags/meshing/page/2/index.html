Уже в #ANSYS #Meshing 16 была реализована возможность распарелелить сеткопостроение для сборок.

В 17-ой версии она получила новое улучшение. Теперь можно обработать сборку Contact Match Group - заставить сетку на контактных поврехностях для обоих тел быть одинаковой, а потом через Node Merge Group слить совпадающие узлы, получив комформную сетку. При этом вы получаете огромное преимущество в корости построения больших сеток как по времени, так и по затрачиваемым ресурсам. Смотрите сами на видео (пример прилагается).

Какие у подхода есть проблемы: Contact Match Group работает только на тетраедральных стетках. Я думаю, что для гексаедральных сеток или сеток из балок и оболочке подогнать совпанедиен узлов не будет большой проблемой при помощу инструмента Sizing.
