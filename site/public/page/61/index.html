Друзья, у моего бывшего коллеги и хорошего человека есть вакансия на PhD студента или Postdoc в New Mexico Tech (США).

Учёба бесплатная со стипендией (в конце текста более точные пояснения). Это хороший путь для эмиграции.

Надо будет работать над исследовательскими проектами по умным волокнам с автономным питанием для не инвазивных носимых устройств мониторинга здоровья, по гибридному производству композитов из нескольких материалов, по молекулярному моделированию процессов/структур/свойств в гибридном производстве. Проекты спонсируются #NASA, #NIH (Национальный Институт Здоровья) и Socorro Ventures (венчурный фонд). Возможно, надо будет вести лабораторные занятия.

Минимальные требования:

  1. Английский уровня между Intermediate и Upper Intermediate
  2. Степень бакалавра в области машиностроения, механики, материаловедения или связанных с ними областей
  3. Опыт исследований
