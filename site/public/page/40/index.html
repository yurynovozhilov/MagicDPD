K&C FEMFRE Version 1.0

FEMFRE - Meshfree Computation Solid Dynamics Solver FEMFRE is a large-deformation, solid mechanics solver for simulating materials and structures in extreme environments. Originally designed as a hybrid Finite Element and Meshfree solver, K&C has since focused FEMFRE development towards an advanced, Meshfree, thermo-mechanical solid dynamics solver. www.kcse.com

У знаменитой в узких кругах консалтинговой компании Karagozian & Case, Inc вышла первая версия их собственного кода для моделирования разрушения при динамическом нагружении FEMFRE (Finite Element and Meshfree solver). А теперь по подробнее. Karagozian & Case, Inc - американская консалтинговая компания созданная во времена второй мировой войны и специализируются на проектирование защитных сооружений и тестировании их. В частности, они создали одну из самых популярных моделей бетона в LS-DYNA MAT_072R3. А несколько лет назад к ним из LSTC ушел один из ключевых разработчиков по SPG. Таким образом, коллеги получили силы для доработки своего аналога SPG, называемого reproducing kernel particle method (RKPM) и кода FEMFRE.
