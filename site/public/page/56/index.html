Reproducing Kernel Particle Method (RKPM)

RKPM - simulation near penetration limit Reproducing Kernel Particle Method (RKPM) [1,2] - a meshfree method - simulation of concrete target using naturally stabilized nodal integration (NSNI) [3].... www.youtube.com

RKPM - это бессеточный метод, наиболее близкий к тому, что в RKPM LS-DYNA носит название SPG. Метод позволяет моделировать разрушение материала на основе механических критериев без потери массы. В сети можно легоко найти реализации данного метода для плоской постановки (см. RKPM2D на GitHUB). Особенно людит данный метод компания Karagosian & Case, которая уже более 70 лет проектирует защитные сооружения, моделирует разрушение бетона, взрывы и терминальную балистику.

Pandas на GPU

GitHub - rapidsai/cudf: cuDF - GPU DataFrame Library cuDF - GPU DataFrame Library . Contribute to rapidsai/cudf development by creating an account on GitHub. github.com

Pandas я люблю еще с тех пор, как мне надо было делать обработку спектров отклика рассчитанных LS-DYNA для оборудования АЭС, в которую бил самолет. Вот тут сеть рассказзал мне про интересную библиотеку cuDF.

cuDF - это библиотека GPU DataFrame для загрузки, объединения, фильтрации и других манипуляций с данными. cuDF использует libcudf, молниеносно быструю библиотеку датафреймов C++/CUDA и столбчатый формат Apache Arrow, чтобы предоставить API pandas с GPU-ускорением.

https://github.com/rapidsai/cudf
