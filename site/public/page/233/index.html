Пощадите конечные элеметны

Пощадите конечные элеметны http://www.dynaexamples.com/examples-manual/contact/tied-1

Существует довольно обычная практика использования методики убийства (#ekill) элементов по физическому (превышение пластических деформаций) или математическому (большое искажение формы элемента) критерию при расчет больших деформаций. Это методика имеет не совсем физичное поведение м четко выраженную сеточную зависимость. Кроме того, вы не соблюдаете закон сохранения массы, а законы надо соблюдать.

У #LSDYNA есть забавный ответ по данной теме - карта *CONSTRAINED_TIED_NODES_FAILURE, позволяющая разорвать КЭ сетку между shell или solid элементами по критерию пластических деформаций или поврежденности. Есть даже готовый пример по ссылке.
